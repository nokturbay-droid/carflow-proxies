# carflow-proxies

Каждые 4 часа GitHub Actions собирает бесплатные прокси из ~180 открытых списков (≈ 376 тыс.
уникальных адресов-кандидатов на 2026-09-29), проверяет их на сайтах каталога в 3 раунда — 8
параллельных осколков, потом сведение — и кладёт результат в `proxies/`:

| Файл | Что внутри |
|---|---|
| `proxies_stable.txt` | стабильные: `адрес  регионы  задержка  страна` (KR / AE / GE / US) |
| `stable_kr.txt`, `stable_ae.txt`, `stable_ge.txt`, `stable_us.txt` | стабильные по региону, по адресу в строке |
| `site_encar.txt`, `site_kbcha.txt`, `site_dubicars.txt`, `site_dubizzle.txt`, `site_myauto.txt`, `site_copart.txt` | прошли ЭТОТ сайт во всех раундах (пул воркера одной площадки — больше регионального) |
| `all_proxies.txt` | все живые (стабильные первыми) |

США (`stable_us.txt`) — только адреса с выходом в США, через которые настоящий поиск Copart вернул
лоты во всех раундах (проверка с отпечатком браузера, `curl_cffi`: Copart за Imperva).

Запустить вручную: вкладка Actions → harvest → Run workflow. Красный запуск = сбой, старый список не тронут.
Источники — `harvest/proxy_sources.txt`. Через эти прокси нельзя передавать логины и ключи.
