# carflow-proxies

Ежедневно (06:00 Бишкек) GitHub Actions собирает бесплатные прокси из ~180 открытых списков,
проверяет их на сайтах каталога в 3 раунда и кладёт результат в `proxies/`:

| Файл | Что внутри |
|---|---|
| `proxies_stable.txt` | стабильные: `адрес  регионы  задержка  страна` (KR / AE / GE) |
| `stable_kr.txt`, `stable_ae.txt`, `stable_ge.txt` | стабильные по региону, по адресу в строке |
| `all_proxies.txt` | все живые (стабильные первыми) |

Запустить вручную: вкладка Actions → harvest → Run workflow. Красный запуск = сбой, старый список не тронут.
Источники — `harvest/proxy_sources.txt`. Через эти прокси нельзя передавать логины и ключи.
